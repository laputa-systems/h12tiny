# h12tiny

h12tiny's packages are developed in [smolith](https://github.com/laputa-systems/smolith).

Registry users keep the package names `h12tiny`, `h12tiny-*`, `laputa-h2-futures-lite`, `laputa-hyper-futures-lite`, and `laputa-fastwebsockets-futures-lite`. New versions are published from smolith.

Git users change the repository URL to `https://github.com/laputa-systems/smolith` and keep the same package selection. Path users point at `crates/h12tiny` and the sibling component and fork directories.

Existing h12tiny commits, tags, and released crates remain available. This repository is not the place for new changes.
